# 误报数据（benchmark 文件级口径）

定义：`FP = generated − matched_generated`，即没有命中“此前未覆盖的 GT”的生成意见。拆成三类：

- `non_gt_file`：落在没有 GT 的文件上；
- `unmatched_on_gt_file`：落在有 GT 的文件上，但语义没匹配上；
- `duplicate_hit`：匹配到的 GT 已被更早的意见覆盖，不计入 precision 分子。

## 读法

- **小 diff（iterS10/iterS20）**：两边误报率接近（RP 69.5%/75.5%，OCR 75.6%/78.2%）；误报主要是 `unmatched_on_gt_file`（RP 31/41、OCR 32/34），说明小 PR 上主要是语义没对上，不是文件靶向。
- **大 diff（iterB2/B5/B10）**：RP 误报率 93.8%/99.2%/98.4%，OCR 38.5%/32.0%/55.3%；RP 的误报以 `non_gt_file` 为主（B10：227/244），是文件广度问题。
- **混合配置**：RP 误报率随大 diff 比例增加：M10 78.5% → M20 88.7% → M50 86.5%；OCR 68.6% → 67.7% → 64.2%。
- **F91**：RP 1242 生成 / 1145 误报（92.2%），OCR 601 / 413（68.7%）；RP 的 non-GT 误报 978 条，OCR 108 条。

> 注意：`non_gt_file` 里的意见不一定是“错误”，可能只是 AACR 没有标注；这里的“误报”是 benchmark 文件级 precision 口径，不等于人工判定的真实误报。

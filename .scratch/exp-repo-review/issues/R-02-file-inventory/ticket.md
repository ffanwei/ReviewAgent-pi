# R-02 · 仓库文件枚举与过滤

- Status: TODO
- Branch: `exp-repo-review`
- Created: 2026-11-24

## 问题

全仓扫描没有 diff 文件清单，必须先确定性枚举「哪些文件值得检视」。

## 目标

- 遍历仓库快照，应用 exclude / ignore 规则；
- 识别二进制、生成物、lockfile、vendor、构建产物并默认跳过；
- 语言分类与单文件大小上限；
- 输出可审计清单：每个文件的状态（可检视 / 跳过）与跳过原因。

## 验收

- 同一快照两次枚举结果字节一致；
- 嵌套目录、符号链接、超大文件、非 UTF-8、空文件均有单测；
- 跳过原因可枚举、可汇总；
- 零模型完成，不发任何模型请求。

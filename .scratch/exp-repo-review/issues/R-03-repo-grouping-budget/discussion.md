## 2026-11-24 · 是否复用 exp-multifile-recall 的分组

- 结论：**复用分组纪律，不复用 `planGroups` 实现**。
- 原因：
  - 输入不同：diff 块 vs 文件树；
  - 单元不同：diff 文本 vs 文件内容；
  - 约束不同：字符 / 文件数 vs 总量 / 忽略规则 / 二进制 / 生成物 / 优先级；
  - 输出不同：待检视 shard diff vs 待检视文件集。
- 可复用：文件数 + 字符双上限、确定性排序、不拆单元、截断留痕、组摘要、`directory` / `language` 键、单测形态。

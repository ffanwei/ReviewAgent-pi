# R-04 · 全仓扫描执行路径

- Status: TODO
- Branch: `exp-repo-review`
- Created: 2026-11-24

## 问题

现有 `review-run.ts` 以 diff 为入口，分片 / 分组执行、覆盖账本、证据门都建立在变更行上。全仓扫描需要独立的执行适配层。

## 目标

- 新增独立 run mode 适配层，消费 R-03 的分组计划；
- 逐组独立检视，组失败不影响其他组；
- 尽量复用现有六阶段循环与证据门；
- 不改 `review-run.ts` 主路径，或只做明确记录的最小接线。

## 验收

- 单组 / 多组路径均可跑通；
- findings 行锚点指向真实现有行；
- 组失败隔离，审计可定位；
- 与 MR 路径的配置 / 产物不互相污染；
- 有零模型 dry-run 覆盖执行计划。

## 依赖

R-01、R-03；R-05 输出契约可并行。

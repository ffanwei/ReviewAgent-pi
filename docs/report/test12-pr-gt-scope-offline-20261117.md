## 5. 结论

1. **去除非 GT 文件对本次只贡献 1 条**：P 0.400 → 0.410。此前 0.294 → 0.385 的提升主要来自去除非 PR 文件（错误 diff 范围）。
2. **全部过滤后，本次 P 41.0% / R 28.8% / B 33.8%**；旧 baseline B 39.3%、OCR 50.7%。本次仍低于旧 baseline。
3. **小 diff 的差距不是文件范围造成的**：过滤到 PR+GT 文件后，本次 B 0.389，旧 baseline 0.465、OCR 0.471。剩余差距来自“同文件不同问题”和覆盖。
4. **大 diff 的差距主要是覆盖**：过滤后本次只剩 1 条命中（ragflow 1/6），FreeCAD 0/13；OCR 覆盖 12/19。precision 100% 是因为只剩 1 条，不代表覆盖能力。
5. OCR 去掉 FreeCAD 的 2 条非 GT 文件意见后，P 从 0.510 升到 0.532；小 diff 不变（它本来就没有非 GT 文件意见）。

## 6. 口径限制

1. 离线重算：只删除已有意见，不改变模型在正确 4/16 文件 diff 上的行为；这是现有结果的精度上界 / 覆盖下界。
2. `FreeCAD@699b45c` 的跳过无法通过过滤恢复。
3. 单次运行、judge 单轮；小样本噪声大。
4. `current` 使用 `findingScope=true` + 分组 + 规则目录，配置与其它三行不同。
